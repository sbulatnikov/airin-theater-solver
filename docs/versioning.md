# Версионирование

Приложение v2 и его движок используют Semantic Versioning: `MAJOR.MINOR.PATCH`.

Это версионирование компонентов. Весь репозиторий дополнительно имеет общий календарный номер и единый Git-тег; процесс описан в [документе о релизах](releases.md).

- **MAJOR** — несовместимое изменение правил, API движка или формата состояния;
- **MINOR** — новая обратно совместимая возможность;
- **PATCH** — исправление без изменения публичного поведения или исправление ошибочного расчёта в рамках подтверждённых правил.

Номер приложения `@airin-play/v2` и движка `@airin-play/core/v2` синхронизирован. Используйте только скрипт:

```bash
pnpm version:set 2.3.0
```

Скрипт проверяет формат SemVer, обновляет оба package manifest и строку версии v2 в корневом README. Версия попадает в интерфейс, собранный HTML и debug-снепшот из `package.json`, поэтому дублировать её в исходном коде не нужно.

После изменения:

1. добавьте пользовательское описание в `CHANGELOG.md` под `Unreleased`;
2. выполните `pnpm test`;
3. включите изменение версии в тот же commit, что и соответствующее изменение поведения.
