# Версионирование

Приложения и их движки используют Semantic Versioning: `MAJOR.MINOR.PATCH`.

- **MAJOR** — несовместимое изменение правил, API движка или формата состояния;
- **MINOR** — новая обратно совместимая возможность;
- **PATCH** — исправление без изменения публичного поведения или исправление ошибочного расчёта в рамках подтверждённых правил.

Поколения имеют независимые линии:

- v1: приложение `@airin-play/v1` и движок `@airin-play/core/v1`;
- v2: приложение `@airin-play/v2` и движок `@airin-play/core/v2`.

Внутри одного поколения номер приложения и движка синхронизирован. Используйте только скрипт:

```bash
pnpm version:set v1 1.9.0
pnpm version:set v2 2.3.0
```

Скрипт проверяет формат SemVer и обновляет оба package manifest. Версия попадает в интерфейс, собранный HTML и debug-снепшот из `package.json`, поэтому дублировать её в исходном коде не нужно.

После изменения:

1. обновите документацию и changelog, когда он появится;
2. выполните `pnpm test`;
3. включите изменение версии в тот же commit, что и соответствующее изменение поведения.
