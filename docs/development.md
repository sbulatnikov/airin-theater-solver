# Локальная разработка

## Требования

- Git;
- Node.js 24;
- pnpm 11 через Corepack.

Версия Node зафиксирована в `.nvmrc` и `.node-version`, версия pnpm — в `package.json`. Все команды одинаковы для Windows, Linux и macOS.

## Установка

```bash
git clone <repository-url>
cd AirinPlaySolver
corepack enable
pnpm install --frozen-lockfile
```

## Dev-сервер

```bash
pnpm dev:v1
pnpm dev:v2
```

Команды запускаются отдельно. Для одновременной работы откройте два терминала.

## Проверки

```bash
pnpm typecheck
pnpm test:unit
pnpm build
pnpm check
pnpm test
```

`pnpm test` выполняет весь набор и должен проходить перед созданием патча или pull request.

Biome является единственным линтером и форматтером. Для автоматического исправления безопасных замечаний и форматирования используйте `pnpm check:write`; для проверки без изменения файлов — `pnpm check`.

## Работа с конкретным подпроектом

```bash
pnpm --filter @airin-play/v1 typecheck
pnpm --filter @airin-play/v1 build
pnpm --filter @airin-play/v2 typecheck
pnpm --filter @airin-play/v2 build
```

## Тесты расчётного ядра

Тесты не зависят от одной записанной партии. Они изолированно проверяют каждое согласованное правило: вклад всех типов реплик, общий цвет, порог равенства, парное и тройное равенство, первый ход, порядок цветов, детерминизм и свойства рассчитанного маршрута.

При уточнении механики сначала добавьте минимальный воспроизводящий пример правила, затем меняйте движок. Исправление общего правила должно проверяться для обоих поколений.

## Что не коммитить

- `node_modules/`;
- `.build/`;
- `dist/`;
- скачанные debug-снепшоты;
- локальные настройки IDE.

Эти пути уже указаны в `.gitignore`.
