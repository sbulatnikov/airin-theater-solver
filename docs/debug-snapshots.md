# Диагностические снепшоты

Кнопка с иконкой жучка скачивает текстовый файл, содержащий одну Base64-строку. После декодирования это UTF-8 JSON со всем состоянием, необходимым для воспроизведения ошибки.

## Содержимое

- версия приложения, вариант интерфейса и версия движка из его версионного пути;
- время, адрес страницы без query-параметров и fragment, браузер, язык и размер окна;
- активные правила расчёта;
- фактическая история ходов;
- текущие поля ввода и сообщения валидации;
- цветовые очки и восторг после каждого хода;
- проанализированные варианты;
- идеальные кандидаты и маршрут v2;
- проверки целостности сумм.

Base64 — это кодирование, а не шифрование. Снепшот содержит всю историю партии, введённые варианты, сведения о
браузере и размере окна. Адрес сохраняется без query-параметров и fragment, чтобы случайно не включить токены или
другие приватные параметры ссылки. Перед публичной публикацией файл всё равно следует просмотреть после декодирования.

## Декодирование в браузере

Прочитайте содержимое файла в переменную `base64`, затем выполните в консоли:

```js
const bytes = Uint8Array.from(atob(base64.trim()), (char) => char.charCodeAt(0));
const snapshot = JSON.parse(new TextDecoder().decode(bytes));
console.log(snapshot);
```

## Декодирование в Node.js

```js
import { readFile } from "node:fs/promises";

const base64 = await readFile("airinplay-debug.txt", "utf8");
const snapshot = JSON.parse(Buffer.from(base64.trim(), "base64").toString("utf8"));
console.dir(snapshot, { depth: null });
```

При сообщении об ошибке приложите снепшот и опишите, какое значение показала игра вместо рассчитанного приложением.
