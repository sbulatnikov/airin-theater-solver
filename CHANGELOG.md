# Changelog

Здесь хранится полная пользовательская история проекта. Рабочие pull requests добавляют записи в `Unreleased`, а
перед Code Freeze выбранные изменения получают номер и дату стабильного релиза.

## Unreleased

## 2026.3 — 2026-08-10

### Добавлено

- ходы ИИ с обычным цветовым вкладом и без увеличения восторга;
- подтверждаемая запись непрознесённой реплики со штрафом восторга до нижней границы `0` и без цветового вклада.

## 2026.2 — 2026-08-09

### Удалено

- код, публичный API, команды, production-маршрут и документация первого поколения v1; корень сайта продолжает открывать v2.

## 2026.1.1 — 2026-08-09

### Исправлено

- CI рабочих веток после подготовки кеша зависимостей параллельно выполняет пять напрямую обязательных проверок: Biome, TypeScript, unit, production build и Playwright E2E;
- только ветки `rc/*` получают отдельный ручной workflow Code Freeze, который блокирует ветку и создаёт неизменяемый RC-тег;
- обновление `main` теперь запускает единый стабильный release pipeline: тег, артефакты, GitHub Release и GitHub Pages;
- hotfix проходит в `main` исключительно через pull request и увеличивает только patch без создания release candidate.

## 2026.1 — 2026-08-09

Компоненты релиза: v1 `1.9.0`, v2 `2.3.0`.

### Добавлено

- светлая и тёмная темы с системным выбором и сохранением настройки;
- полноценная мобильная раскладка с safe-area и touch-элементами от 44 px;
- Playwright E2E для обеих версий, целевых разрешений и debug-снепшотов;
- публикация RC и стабильных GitHub Releases с готовыми артефактами;
- Dependabot для pnpm и GitHub Actions.

### Изменено

- интерфейс расширен для 1440–3440 px и переведён на шрифт Onest;
- микротексты сокращены для быстрого выбора реплики;
- публичные контракты движка отклоняют некорректные истории и глубину прогноза;
- версия репозитория отделена от независимых SemVer-линий v1/v2.

### Безопасность

- GitHub Actions закреплены по полным commit SHA и получили минимальные permissions;
- production HTML защищён CSP с SHA-256-хешами встроенных script/style;
- debug-снепшот больше не сохраняет query и fragment адреса страницы;
- сборка проверяет автономность, поколение движка и защитные метаданные.

Правила начисления очков в этом релизе не изменялись.
