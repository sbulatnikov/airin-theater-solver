# Суфлёр

«Суфлёр» помогает пройти театральную мини-игру «Аллодов Онлайн» с первого раза: фиксирует сыгранные реплики, считает восторг зала и рекомендует лучший из доступных вариантов.

Проект содержит два независимо собираемых приложения:

- **v1 · 1.8.1** — классический ввод трёх предложенных реплик;
- **v2 · 2.2.1** — быстрый выбор вариантов и рассчитываемая победная цепочка.

Обе версии собираются в автономный `index.html`: его можно открыть локально, отправить другому человеку или опубликовать на GitHub Pages.

## Быстрый старт

Нужны Node.js 24 и pnpm 11. Проект одинаково работает на Windows, Linux и macOS.

```bash
corepack enable
pnpm install
pnpm dev:v2
```

Для запуска первой версии используйте `pnpm dev:v1`.

Полная проверка проекта:

```bash
pnpm test
```

Команда запускает Biome, проверяет TypeScript и Vue, выполняет тесты расчётных движков, собирает обе автономные страницы, проверяет изоляцию версий и прогоняет пользовательские сценарии Playwright в Chromium.

## Сборка

```bash
pnpm build
```

Результат создаётся локально и не хранится в Git:

```text
dist/
  index.html       переход на актуальную v2
  v1/index.html    автономная версия v1
  v2/index.html    автономная версия v2
```

## Устройство репозитория

```text
apps/
  v1/                 приложение первого поколения
  v2/                 приложение второго поколения
core/
  shared/             общие типы и базовый класс движка
  v1/                 класс Engine первого поколения
  v2/                 класс Engine второго поколения
packages/
  ui/                 общие Vue-компоненты и стили
scripts/              сборка публикации и управление версиями
tests/
  core/               независимые тесты правил, состояния и стратегии
docs/                 подробная документация
```

Это pnpm-workspace. Расчётное ядро предоставляет публичные точки входа `@airin-play/core/v1`, `@airin-play/core/v2` и `@airin-play/core/shared`. Оба версионных модуля экспортируют класс с одинаковым именем `Engine`; поколение определяется исключительно путём импорта.

Исходный код проверяется и форматируется Biome:

```bash
pnpm check
pnpm check:write
```

## Версии

Версия приложения и его движка меняется одной командой:

```bash
pnpm version:set v1 1.9.0
pnpm version:set v2 2.3.0
```

После изменения версии необходимо выполнить `pnpm test`.
